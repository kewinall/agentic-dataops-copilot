# Contributing / 貢獻指南

## 中文

1. 建立 feature branch。
2. 安裝開發環境：`make install`。
3. 執行 `make lint` 與 `make test`。
4. PR 需說明問題、設計、測試方式與安全影響。
5. 新增 action tool 時，必須說明 approval、allowlist、audit 與 rollback 設計。

## English

1. Create a feature branch.
2. Install development dependencies with `make install`.
3. Run `make lint` and `make test`.
4. Pull requests should describe the problem, design, tests, and security impact.
5. New action tools must document approval, allowlisting, audit, and rollback behavior.
