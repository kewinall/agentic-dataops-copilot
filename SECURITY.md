# Security Policy / 安全政策

## 中文

此專案目前為展示與測試用途。請勿將正式環境的認證資訊、客戶資料或其他敏感資訊提交至 repository。

v0.1 的 tools 為 advisory-only，不會直接修改 Kubernetes、Database 或 Cloud 資源。未來加入 action tools 時，必須具備 approval gate、allowlist、audit trail 與 rollback 設計。

## English

This repository is intended for demonstration and testing. Do not commit production authentication material, customer data, or other sensitive information.

v0.1 tools are advisory-only and do not directly mutate Kubernetes, database, or cloud resources. Future action tools must include approval gates, allowlists, audit trails, and rollback design.
